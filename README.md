# Frontend Mentor - Social links profile

![Design preview for the Social links profile coding challenge](./preview.jpg)

This is my solution to the Social Links Profile challenge on Frontend Mentor.

Overview

The goal of this project was to recreate the provided design as closely as possible and practice building a simple responsive card using HTML and CSS.

Built with
Semantic HTML5
CSS
Flexbox
Custom fonts
CSS box model
What I practiced

During this project, I practiced:

Using Flexbox to position and align elements
Working with flex-direction, justify-content, and align-items
Using gap, margin, and padding
Understanding the CSS box model and box-sizing
Styling lists and links
Using descendant selectors such as .list-links li and .list-links a
Working with font-size, font-weight, and letter-spacing
Connecting a local font with @font-face
Using DevTools to inspect element sizes and rendered fonts
